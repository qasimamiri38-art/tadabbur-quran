# تدبّر القرآن

وب‌اپلیکیشن فارسی/عربی برای مطالعهٔ قرآن، انتخاب ترجمه و تفسیرهای موجود در AlQuran Cloud، جست‌وجو، نشان‌گذاری آیات و پخش صوت.

## اجرای برنامه

این پروژه فرانت‌اند ساده است و مرحلهٔ build ندارد. برای آزمایش محلی، فایل‌ها را با یک وب‌سرور محلی باز کنید؛ برای نمونه:

```bash
python -m http.server 8000
```

سپس `http://localhost:8000` را باز کنید. بازکردن مستقیم فایل با `file://` برای Service Worker کار نمی‌کند. برای انتشار، GitHub Pages را روی شاخهٔ `main` و پوشهٔ ریشه تنظیم کنید.

## فایل‌های اصلی

- `index.html` — رابط و منطق فعلی برنامه؛ داده‌ها را هنگام اجرا از API می‌گیرد.
- `manifest.webmanifest` — مشخصات نصب‌پذیری وب‌اپ.
- `sw.js` — کش پوستهٔ برنامه و پاسخ‌های موفق API برای استفادهٔ آفلاین محدود.
- `icon-512.png` — آیکن برنامه.
- `quran-*.json` و `quran-uthmani.txt` — فایل‌های دادهٔ موجود در مخزن؛ نسخهٔ فعلی رابط بر اساس `index.html` از AlQuran Cloud API استفاده می‌کند.
- `README-FA.md` — راهنمای فارسی.

## وابستگی و محدودیت

متن، ترجمه‌ها و فهرست تفسیرها از [AlQuran Cloud API](https://alquran.cloud/api) دریافت می‌شوند؛ برای دریافت نخستین داده‌ها و صوت آنلاین اینترنت لازم است. کش Service Worker استفادهٔ آفلاین را تضمین نمی‌کند. نام و مجوز منبع ترجمه‌ها/تفاسیر را پیش از استفادهٔ عمومی بررسی کنید.

## نگهداری

برای جلوگیری از شکستن مسیرهای GitHub Pages، فایل‌های فعلی داده و تصویر تا زمان بررسی ارجاع‌ها جابه‌جا نشده‌اند. هنگام توسعهٔ بعدی، CSS و JavaScript را پس از آزمون به فایل‌های جداگانه منتقل کنید و برای هر فایل داده مشخص کنید که آیا برنامه واقعاً از آن استفاده می‌کند یا نه.
