# تدبّر القرآن — نسخه تکمیل‌شده رابط مطالعه

## نصب و انتشار
1. از مخزن GitHub خود نسخه پشتیبان بگیرید.
2. در مخزن `qasimamiri38-art/tadabbur-quran` فایل `index.html` را با فایل این بسته جایگزین کنید.
3. دو فایل `manifest.webmanifest` و `sw.js` را در ریشه همان مخزن اضافه کنید.
4. فایل‌های داده و تصویر قبلی را حذف نکنید؛ نسخه جدید از API عمومی قرآن استفاده می‌کند و برای تصویر قبلی وابستگی ندارد.
5. در GitHub به Settings → Pages بروید و انتشار از شاخه `main` و پوشه `/ (root)` را فعال نگه دارید.
6. سایت را در Safari آیپد باز کنید؛ Share → Add to Home Screen.

## امکانات
- فهرست ۱۱۴ سوره و نمایش متن عربی با رسم عثمانی
- انتخاب ترجمه فارسی از فهرست editionهای فارسی موجود در منبع
- انتخاب تفسیر فارسی در صورت وجود edition تفسیری
- جست‌وجو در متن عربی/ترجمه سوره انتخاب‌شده
- پخش آیه با قاری مشاری العفاسی
- نشان‌گذاری آیات و ذخیره محلی در همان مرورگر
- ذخیره آخرین سوره مطالعه‌شده و تنظیم اندازه قلم
- manifest و service worker برای نصب‌پذیری و کش اولیه

## منابع و دقت
متن و داده‌ها هنگام اجرا از AlQuran Cloud API دریافت می‌شوند: https://alquran.cloud/api
فهرست ترجمه‌ها و تفاسیر فارسی از API درخواست می‌شود؛ موجود بودن آن‌ها به فهرست فعلی سرویس بستگی دارد. این بسته خودش ترجمه یا تفسیر جدیدی جعل نمی‌کند.
برای ترجمه دری مستقل، تفسیر منتخب و محتوای آموزشی اختصاصی باید منبع/مجوز مناسب انتخاب و سپس جداگانه افزوده شود.
صوت آنلاین است و برای پخش به اینترنت نیاز دارد. حالت آفلاین کامل و پخش آفلاین صوت تضمین نشده است.
